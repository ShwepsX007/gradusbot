ИИ · GOOGLE GEMINI

Модель, промпт и ключи

Проверяем SSH-туннель…

Ключи хранятся на сервере в файле 0600 без шифрования; root и пользователь службы имеют доступ. Не присылайте ключи в чат. Отправленные погодные данные и промпт обрабатываются Google; запрос может быть платным. Не включайте секреты в промпт.

Лимиты Gemini принадлежат проекту, а не ключу. Указывайте точный Google Cloud Project ID. Автопереключение после 429 разрешено только для проектов, на использование квот которых у вас есть разрешение Google; одинаковые проекты не дают отдельную квоту.

Ключи Gemini

Ключи не загружены.

Переключение выполняется только по ответу 429 и не выполняется после таймаута или неизвестного результата. Изменение ключей не отменяет уже начатый запрос.

POLYMARKET · АККАУНТ

Ключи для сверки с биржей

Проверяем защищённое подключение…

Если вы пополняете Polymarket через MetaMask, для сверки укажите торговый кошелёк из профиля Polymarket (funder), а ключ MetaMask используется для подписи. Эти адреса могут отличаться; пополнение само по себе не определяет тип кошелька.

Приватный ключ и секреты хранятся на сервере в файле с правами 0600, без шифрования. При компрометации сервера средства могут быть украдены. Вводите данные только через SSH-туннель и никогда не присылайте их в чат.
Для замены введите комплект заново. Само сохранение не отправляет ордер и не проверяет работоспособность аккаунта.
